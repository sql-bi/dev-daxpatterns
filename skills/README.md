# Skills

LLM skills that apply a DAX Patterns library to a specific semantic model.
One folder for each pattern, with a `SKILL.md` file.

| Pattern | Skill |
|---|---|
| Cumulative total | [CumulativeTotal/SKILL.md](CumulativeTotal/SKILL.md) |

The skills are not part of the packages published on DAX Lib. The publish workflows copy only `src/<Pattern>/`.
